# 🎌 Anime Verse

A premium anime discovery app built with React + Jikan API.

## Features
- 🏠 Home with trending, seasonal & top anime
- 🔍 Search any anime
- 🎭 Browse by genre
- 📄 Full anime detail page with trailer & characters
- ❤️ Watchlist (saved locally)

## Tech Stack
- React 18 + Vite
- Framer Motion
- React Router DOM
- Jikan API (free, no key needed)
- Axios

## Run Locally

```bash
npm install
npm run dev
```

Open http://localhost:5173
